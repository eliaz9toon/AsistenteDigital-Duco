¿Cómo leer esta pantalla?
  • 🔑 ID automático: número que Oracle asigna solo a cada fila nueva (1, 2, 3…). No se reutiliza si se borra una fila, por eso puede haber saltos. Identifica la fila dentro de su tabla.
  • 🔗 apunta a OTRA_TABLA: esa columna guarda el ID de una fila de otra tabla (por ejemplo, ID_SESION en MENSAJES dice a qué conversación pertenece el mensaje). Al lado del número se muestra, en gris, a qué corresponde.
  • 🕒 fecha y hora: cuándo se creó o cambió el dato. Se muestran al final de cada fila.
  • Las tablas están agrupadas por módulo y, dentro de cada módulo, primero las que no dependen de otras. Las que dicen «vacía» todavía no reciben datos de la aplicación.
  • Los registros se listan del más reciente al más antiguo. Pulsa el nombre de una tabla relacionada para saltar a ella.
